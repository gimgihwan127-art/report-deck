# 리포트덱

보고 내용을 붙여넣고 사진·영상을 넣으면 슬라이드 레이아웃을 자동으로 잡아주는 웹 프레젠테이션 도구입니다.
설치할 것 없이 `index.html` 파일 하나로 동작합니다.

## 깃허브 페이지로 운영하기

1. 저장소에 `index.html`을 올립니다.
2. 저장소의 Settings → Pages → Branch를 `main` / `(root)`로 정하고 저장합니다.
3. `https://<계정>.github.io/<저장소>/` 주소로 접속합니다.

## 디자인 테마

상단의 테마 버튼으로 고릅니다. 같은 내용이 테마에 맞는 배치와 색으로 다시 그려집니다.

- **코발트**: 밝은 바탕에 파란 강조, 가는 선과 넓은 여백
- **스테이지**: 검정·남색·빨강 바탕에 코랄과 골드 포인트, 굵은 제목과 둥근 카드

새 테마는 `index.html`의 `THEMES`에 항목을 하나 추가하고 `.th-<이름>` 스타일을 쓰면 됩니다.

## 보고 내용은 어디에 저장되나요

작성 중인 글과 사진, 영상은 접속한 사람의 브라우저에만 저장됩니다. 깃허브로 전송되지 않습니다.
다른 컴퓨터에서 이어서 하거나 공유하려면 **파일로 저장**을 눌러 `.html` 파일을 만드세요. 그 파일 하나로 발표와 수정이 모두 됩니다.

저장한 보고서를 링크로 공유하려면 저장소에 `reports` 폴더를 만들어 올리면 됩니다.
공개 저장소에 올린 보고서는 누구나 볼 수 있으니 사내 자료는 올리지 마세요. 파일 하나의 최대 크기는 100MB(웹 업로드는 25MB)입니다.

## 쓸 수 있는 파일

- 글: 붙여넣기, `.txt` `.md` `.docx` `.pptx` `.csv`, 엑셀에서 복사한 표
- 사진: JPG, PNG, WebP, GIF, SVG
- 영상: MP4(H.264), WebM

한글(.hwp) 파일은 내용을 복사해 붙여넣으세요.
